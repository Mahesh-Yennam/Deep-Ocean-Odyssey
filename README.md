# Deep Ocean Trench Odyssey 🌊⚓

A vertical bathymetric exploration application taking users on an 11,000-meter dive from the sunlit surface waves to the hadal abyss of the Challenger Deep in the Mariana Trench. Built with 100% vanilla client-side web technologies (HTML5 Canvas, CSS3, JavaScript, Web Audio API) with zero remote dependencies.

Part of the **Gamility Interactive Explorer Hub** collection.

---

## ✨ Features

- **11,000m Vertical Bathymetric Descent Elevator**:
  - Continuous vertical dive through the 5 planetary oceanic layers:
    - **Epipelagic (Sunlight Zone: 0–200m)**: Coral reefs, Bottlenose Dolphins, Green Sea Turtles, Great White Sharks, Blue Whales.
    - **Mesopelagic (Twilight Zone: 200–1,000m)**: Dim twilight, Barreleye Fish with upward tubular eyes, Lanternfish, Oarfish, diving Sperm Whales.
    - **Bathypelagic (Midnight Zone: 1,000–4,000m)**: Total blackness, Humpback Anglerfish with glowing esca lure, Gulper Eels, Vampire Squid.
    - **Abyssopelagic (Abyssal Zone: 4,000–6,000m)**: 2°C frigid water, Dumbo Octopus, Tripod Fish, hydrothermal vent black smokers (350°C mineral spires).
    - **Hadalpelagic (Hadal Trenches: 6,000–11,000m Challenger Deep)**: Extreme hydrostatic pressure (1,100 ATM / 16,000 PSI), Mariana Snailfish, supergiant amphipods.
- **Live Bathymetric Telemetry Dashboard**:
  - Real-time readouts for depth (meters / feet toggle), hydrostatic pressure in ATM and PSI ($P = 1 + 0.1 \times \text{depth}$), ambient temperature gradient ($28^\circ\text{C} \rightarrow 1.5^\circ\text{C}$), and sunlight penetration ($100\% \rightarrow 0\%$).
- **Submersible Floodlight & Bioluminescence Mode**:
  - Toggle between powerful exploration floodlights and **Bioluminescence Night-Vision**, revealing radiant chemical photophore glows (luciferin/luciferase reactions) on deep-sea fauna in the dark.
- **Depth Landmark & Scale Comparator**:
  - Visual depth milestones comparing scuba diving records, the Eiffel Tower, Burj Khalifa, the Titanic wreck at 3,800m, and Mount Everest inverted into the Mariana Trench ($8,848\text{m}$ peak vs $10,994\text{m}$ trench depth).
- **Procedural Hydro-Acoustic Audio Synthesizer (Web Audio API)**:
  - Ambient underwater hydrophone hums, deep hull pressure creaks, and rhythmic active sonar pings.
- **Ocean Trench Mastery Quiz**:
  - 3 progressive difficulty tiers (Reef Snorkeler, Deep Diver, Hadal Oceanographer) testing oceanographic principles.
- **Real High-Resolution Specimen Photography**:
  - Photorealistic open-access photography across all 24 deep-sea species and geographic landmarks (Titanic wreck bow, Challenger Deep bathymetric survey, and Black Smoker hydrothermal chimneys) with graceful fallback avatars and subtle micro-zoom interactions.
- **100% Client-Side Privacy**: Zero tracking, zero remote database calls, zero telemetry.

## 🎮 Controls

| Action | Control |
|---|---|
| **Dive / Ascend** | Vertical Scroll / Depth Slider / Zone Quick Jump Buttons |
| **Zone Jump Pills** | Click `[Sunlight]`, `[Twilight]`, `[Midnight]`, `[Abyss]`, `[Titanic]`, `[Hadal]` |
| **Toggle Bioluminescence** | Click `💡 Floodlights / 🟢 Bioluminescence` in Sub HUD |
| **Inspect Species Dossier** | Click any creature or feature card |
| **Audio Toggle** | Click Speaker icon in top navigation ribbon |
